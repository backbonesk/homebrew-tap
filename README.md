# BACKBONE Homebrew Tap

[Homebrew](https://brew.sh) packages for tools made by [BACKBONE, s.r.o.](https://www.backbone.sk)

```sh
brew tap backbonesk/tap
```

## Available packages

| Package   | Install                                      | Description                                                    |
|-----------|----------------------------------------------|----------------------------------------------------------------|
| [IP Calc](https://github.com/backbonesk/ipcalc-macos) | `brew install --cask backbonesk/tap/ip-calc` | Offline IPv4/IPv6 subnet calculator in a Spotlight-style panel |

Installing with the full name (`backbonesk/tap/<package>`) adds the tap automatically.
Updates arrive with the usual `brew update && brew upgrade`.

## Issues

Please report problems with a tool in that tool's repository. Use this repository's issues only
for problems with the packages themselves (for example, a failing install).
